# PyLink

**A Python-based real-time messaging system.**

PyLink is a client-server messaging application designed to explore network programming, asynchronous communication, concurrency, and software architecture using Python.

The project provides a shared chat environment accessible through two independent clients:

- **Python CLI Client** — an interactive terminal-based messaging client.
- **Web Client** — a browser-based interface built with HTML, CSS, and JavaScript.

## Features

- User registration and authentication
- Real-time messaging using WebSockets
- Persistent message history
- PostgreSQL database integration
- Independent authentication for CLI and browser clients
- Automated tests
- Performance and concurrency experiments

> PyLink is developed as an educational software engineering project, with an emphasis on understanding the underlying technologies and architectural decisions.

## Tech Stack

- Python
- FastAPI
- Uvicorn
- PostgreSQL
- SQLAlchemy
- Alembic
- JavaScript, HTML, CSS
- pytest
